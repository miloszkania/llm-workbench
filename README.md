# llm-pipeline
LLM pipeline for the Software Quality Seminar (SWQ).

# Setup
- To run the pipeline locally, first install all the requirements from `requirements.txt`.
- Then, you can run the project with `python3 -m streamlit run main.py`.

### The project uses following `.env` variables:
- **OPENROUTER_API_KEY** - API Key for OpenRouter
- **DB_PATH** - Path to a SQLite database
